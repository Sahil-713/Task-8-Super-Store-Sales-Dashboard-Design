# 🧾 Task 8 – Super Store Sales Dashboard Design

## 📌 Objective:
To create an interactive Power BI dashboard that visualizes sales performance by product category, region, and time (month-year).

---

## 📂 Dataset:
Used `SuperStore Sales DataSet.xlsx` containing the following key columns:
- Order Date
- Region
- Category
- Sales
- Profit

---

## 📊 Dashboard Features:
- **Line Chart:** Monthly sales trend (Month-Year format).
- **Bar Chart:** Sales distribution across four regions – West, East, Central, South.
- **Donut Chart:** Sales share by product categories – Technology, Furniture, Office Supplies.
- **Slicer:** Region-based slicer for dynamic filtering.
- **Color Coding:** Used to highlight top-performing regions and categories.

---

## 🔍 Key Insights:
1. **Technology** category accounts for the largest portion of sales (41.11%).
2. The **West** region recorded the highest total sales.
3. Sales performance peaked in **December 2020**, indicating strong year-end activity.
4. Despite being the smallest contributor, **Furniture** still forms a significant part of sales.

---

## 🛠 Tools Used:
- **Power BI** for visualization
- **Data cleaning** done within Power BI (no external Python tools used)

---

## 📤 Deliverables:
- Dashboard exported as PDF (`Super Store Analysis.pdf`)
- Insights (this file)
- Dataset (SuperStore Sales DataSet.xlsx)

---
